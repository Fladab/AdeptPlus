# Adept+

## About the Project

As a new **Dead by Daylight** player, one thing quickly became frustrating for me: there was no simple application that allowed me to keep track of my **Adept achievements**, especially for players using the **Epic Games Store**.

Most of the existing tools were either designed only for Steam users, focused on builds and statistics, or simply didn't provide an easy way to mark completed Adept achievements. I wanted something clean, fast, and dedicated to one purpose—tracking my progress.

Instead of waiting for someone else to create it, I decided to build it myself.

This project is a desktop application that allows players from both **Steam** and the **Epic Games Store** to keep track of every Adept achievement in **Dead by Daylight** using a simple checklist interface.

Whether you are trying to complete every Killer or Survivor Adept, this application helps you see your progress at a glance without having to remember which characters you have already finished.



## Features

* ✔️ Track every Adept achievement in Dead by Daylight
* ✔️ Support for both Steam and Epic Games Store players
* ✔️ Simple and easy-to-use checklist interface
* ✔️ Save your progress
* ✔️ Lightweight desktop application
* ✔️ Clean and modern design



## Why I Created This

This project started as a personal tool.

When I began playing Dead by Daylight, I was surprised that there wasn't a dedicated application for marking completed Adept achievements, especially for Epic Games Store players.

Keeping track manually quickly became confusing, particularly as the roster of Killers and Survivors continued to grow.

I wanted a solution that was simple, convenient, and designed specifically for this purpose. Since I couldn't find one that matched what I was looking for, I decided to create my own.

My hope is that other players will find it just as useful as I do.
